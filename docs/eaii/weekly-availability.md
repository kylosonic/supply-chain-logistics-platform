## 4. Constraints I am declaring up front

Stating these now rather than discovering them mid-program:

1. **One founder, no employees.** I am the only full-time person. The five-day commitment is
   therefore real time, not time shared with a co-founder or a day job. This is an advantage for
   focus and a risk for single-point dependency — I would use program time to bring on the first
   hire or contractor.
2. **Travel.** I can attend in-person program sessions and on-site customer visits. Multi-day travel
   is possible with roughly one week of notice so I can schedule around customer commitments.
3. **One open human verification gate.** Confirming the CBE and Dashen transfer fee schedules
   (5,000–50,000 ETB band, ±1,000 ETB tolerance) requires a human action that I intend to close
   during the program. It blocks *paid* launch, not product development.
4. **Production database access.** The live deployment's database credentials need to be reissued
   before the hosted environment serves signups again. This is a known, scoped operational task, not
   a product gap — the full launch funnel is verified working against the same code and schema.
